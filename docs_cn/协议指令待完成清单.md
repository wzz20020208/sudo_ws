# 协议层指令清单

来源：《伺服电机控制协议 V4.3--中文版》`docs_cn/电机说明/_resources/伺服电机控制协议V4.3--中文版.pdf`
对照：`include/motor_can/protocol/rh_protocol.hpp` 中的 `RhCmd` 枚举与 `encode_*`/`decode_*` 函数。

实现流程：确认方案 → 写协议层 + 单测 → 真机验证 → 勾掉。

## 待真机验证（代码已实现，手册示例已通过单测，但未在 X2-7 上实测）

- 0xA6 单圈位置控制（直驱用，X2-7 多圈模式不适用，跳过）
- 0xB3 通讯中断保护时间（⚠️ 安全相关：写之前先确认当前值，避免误触发锁闸）
- 0x20 索引 0x06/0x07 位置限位（⚠️ 单位手册未注明，按 0.01°/LSB 实现，真机确认）

## 已实现（协议层 + 单测；✅ 已真机验证）

- 参数：0x30 读 PID、0x31 写 PID RAM、0x32 写 PID ROM、0x42 读加速度、0x43 写加速度
- 编码器：0x60 多圈位置、0x61 原始位置、0x62 零偏、0x63 写零偏、0x64 当前点写零点、
  0x90 单圈编码器 ✅（直驱用，X2-7 实测有回显）
- 系统：0x20 全索引（0x01 清除多圈值 ✅、0x02 CANID 滤波器 ✅、0x03 错误上报 ✅、
  0x04 掉电保存 ✅、0x05 设置 CANID ✅、0x06/0x07 位置限位）、0x70 运行模式、0x76 复位、
  0x77 开闸 ✅、0x78 锁闸 ✅、0x80 关闭、0x81 停止 ✅、0xB1 运行时间 ✅、0xB2 版本日期 ✅、
  0xB3 通讯中断保护、0xB4 波特率（**仅协议层 + 单测**，改完立即断联，Device 层不暴露）、
  0xB5 电机型号 ✅、0xB6 主动回复 ✅
- 读状态：0x92 多圈角度、0x94 单圈角度、0x9A 状态1、0x9C 状态2、0x9D 状态3 ✅
- 控制：0xA1 转矩、0xA2 速度、0xA4 绝对位置、0xA6 单圈位置、0xA8 增量位置、0xA9 力控位置
- 多电机：0x280 广播 ✅（`MultiMotorController::broadcast_stop/off/position`；实测 ID1+ID2 同时响应；前置失能 0x20/0x02）

## 未实现

| 命令 | 名称 | 说明 | 优先级 |
| :-- | :-- | :-- | :-- |
| 0x400+ID | 运动模式控制 | MIT 式 5 参数（p_des/v_des/t_ff/kp/kd，大端位打包），独立协议族，0x400 节 | 低：需要力/阻抗控制再评估 |

## 已移除 / 不采用

| 命令 | 名称 | 原因 |
| :-- | :-- | :-- |
| 0x79 | CANID 设置（文档第 4 节，0x300 广播） | **X2-7 实测无回复**（读/写 × 广播 0x300 × 按地址 0x140+ID 全测过）。真机改 ID 的命令是 **0x20 索引 0x05**，已实现。不要再按文档把 0x79 加回来 |
| 0xCD / RS485-ID 0x79 | RS485 指令 | X2-7 只有 CAN 接口（接口表无 RS485），不适用 |
