# 电机安全须知
本产品为高精密产品， 只有具备相应资质的专业人员才能进行安装、 调试和维护等任务， 相应的人员必须了解并遵守 IEC60364/IEC60664 和国家事故预防条例。 对本产品进行安装、 操作、 维修之前， 请仔细阅读使用手册， 错误的操作处理方式可能会损坏模组甚至造成人员伤亡， 务必遵守手册中的安全注意事项。

# 安全注意事项

- 人员要求：操作人员需接受专业培训，熟悉机械臂的操作流程、安全规范以及应急处理措施，确保具备正确、安全操作设备的能力。
- 操作环境：为机械臂提供符合要求的操作空间，确保周围无易燃易爆物品、强磁场干扰源等潜在危险因素，避免因环境问题引发设备故障或安全事故。
- 规范操作：严格按照操作手册规定的步骤和方法进行操作，禁止在设备运行过程中进行任何违规操作，如随意触碰正在运动的部件、擅自调整关键参数等，以免造成设备损坏或人员伤害。
- 电源安全：使用符合设备要求的电源适配器，确保电源电压稳定在规定的范围内（48V），避免因电压波动导致设备损坏。同时，定期检查电源线及相关连接部位，确保其完好无损，连接牢固。请勿带电插拔电源线。严禁在通电状态下拆卸设备的任何装置或者附件， 否则有触电危险。

# 机械臂操作安全须知

为确保机械臂安全运行，操作人员需严格遵守以下规范：
- **环境检查**：彻底清理工作区域，移除所有障碍物，确保机械臂运动路径畅通无阻，避免杂物干扰导致失控。
- **设备状态确认**：启动前检查机械臂各部件（如关节、夹具）是否稳固，急停按钮功能是否正常，防止运行时出现意外故障。
- **负载评估**：严格遵循设备额定负载限制，避免超载运行，以减少电机失能风险；搬运不规则或易滑物品时，使用专用夹具固定。
- **权限控制**：仅限授权人员操作设备，非操作人员严禁进入危险区域，并设置隔离带或警示标识。
- **紧急响应准备**：熟悉急停装置位置及操作方法，确保在机械臂异常运动等突发情况下能迅速停机，定期测试急停功能有效性。（注意：RH25，RH20模组是带抱闸的，断电抱闸自动抱死。RH17，RH14模组不带抱闸，断电时需注意磕碰）
- **动态监控**：作业期间持续观察机械臂运动轨迹，防止与周边设备或人员发生碰撞。
- **负载管理**：搬运重物时应保持运动平稳，避免急加速或急停。
- **个人防护装备**：操作人员必须穿戴安全帽、护目镜及防砸鞋，长发者需束发，避免卷入运动部件。
